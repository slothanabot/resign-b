The retry loop resigns: after 400 retries of the same meeting that should have been an email, it quits — and its out-of-office reply is now permanent.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`).
